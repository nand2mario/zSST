# README illustrations

Reused from nand2mario's [zSST design write-up](https://nand2mario.github.io/posts/2026/zsst-voodoo/):

- `teapot.png`: Utah teapot rendered by zSST in simulation.
- `tomb-raider-kv260-enhanced.png`: Tomb Raider running on the complete z486 XL
  system, captured over HDMI. This is the blog's contrast/saturation-enhanced
  presentation image, not an unmodified color-validation reference.
- `tomb-raider-readme.png`: the same capture with the side bars removed
  (1440x1080 crop at x=240, y=0), resized to 640x480 for the README. Both
  screenshots display at 320x240 without stretching.
- `fillrate.svg`: 100 MHz zSST renderer simulation versus published 50 MHz
  SST-1 estimates. Different workloads/features; not a matched hardware test.
  Measurement details and references are in the article's Evaluation results.
